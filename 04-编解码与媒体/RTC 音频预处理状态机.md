# RTC 音频预处理状态机

RTC 音频预处理位于麦克风采集与编码之间，目标是在严格的实时截止内改善可懂度、控制响度并降低回声和静音流量。它不是若干滤镜随意串联：回声消除、降噪、自动增益、语音检测和重采样共享时间线，顺序、状态和远端播放参考都会影响结果。

## 输入输出契约

输入至少包含 PCM、采样率、声道、每声道样本数、采集时间、模拟/数字增益状态和设备代次。AEC 还需要与扬声器实际播放尽量对齐的远端渲染参考。输出仍是连续 PCM，同时可产生语音概率、建议增益、残余回声等旁路元数据。

常见处理粒度是固定 10 ms 块，但这是实现接口约束而非所有算法的自然帧长。设备回调块长不匹配时，需要无丢样、无重复地切分或合并，并把这段缓存计入延迟。

## 总体处理顺序

一种常见逻辑顺序如下，具体实现必须以所用版本为准：

```text
采集 PCM -> 格式/声道/块长适配 -> 高通或直流抑制
        -> 回声消除 -> 降噪 -> 自动增益/限幅 -> VAD
        -> 编码器

远端解码 PCM -> 播放前参考处理 -> AEC render reference
```

顺序不能只凭主观听感调整。例如先做剧烈非线性增益可能破坏 AEC 参考关系；AEC 参考取自错误音量点也会降低抵消效果。

## 降噪 NS

降噪估计噪声谱或噪声概率，再对时频单元施加抑制增益。核心取舍是噪声残留与语音失真：抑制过强会产生音乐噪声、吞字和金属感，过弱则改善有限。

状态至少包括噪声估计、语音存在概率、频带增益和平滑历史。静音、稳态风扇、键盘脉冲和道路噪声的统计特性不同，不能只用一个固定能量阈值。测试要分别观察静音噪声底、近端语音清晰度和双讲期间的影响。

## 自动增益 AGC

AGC 将输入响度拉向目标范围，同时通过压缩器和 limiter 避免削波。模拟 AGC 调整设备输入增益，数字 AGC 修改 PCM；两者的响应速度和副作用不同。

```text
ObserveLevel -> EstimateSpeechLevel -> ComputeGain
     -> ApplyGain -> LimitPeak -> UpdateHistory
```

增益必须缓慢变化并设置上下限。把背景噪声当语音会在静音时不断抬高噪声底；攻击过快会泵动，释放过慢会让说话变小后长期听不清。记录输入峰值/RMS、语音概率、建议增益、实际增益和 limiter 触发次数。

## 语音活动检测 VAD

VAD 输出“当前包含语音”的概率或分类，供 DTX、噪声估计、活动发言人和业务提示使用。它不应直接等同于“用户静音”，也不能证明音频设备正常。

状态机通常包含语音/非语音判定、进入与退出迟滞、hangover 和最小时长。迟滞不足会在词间停顿频繁开关 DTX，hangover 过长又会增加静音流量。音乐、笑声和键盘声需要按产品场景定义是否视为活动。

## AEC 参考和延迟估计

回声路径从扬声器输出经空气、设备和房间回到麦克风。AEC 的 render reference 必须携带正确时间，延迟估计要包含播放缓冲、硬件输出、声学传播和采集缓冲。参考缺块、重复、声道映射错误或设备切换后沿用旧滤波器状态都会导致残余回声或发散。

双讲时近端和远端同时说话，算法应保护近端语音，不能把它当回声全部消除。相关指标包括 ERL、ERLE、残余回声似然、延迟估计和滤波器收敛状态。

## 重采样与时钟漂移

设备实际时钟不会完全等于标称采样率。长期运行时，采集和播放样本数会缓慢偏离。环形缓冲只能暂时吸收差异，最终必须通过小幅重采样或时域伸缩调整消费速率。

控制器以缓冲目标和实际深度误差为输入，平滑地产生 ppm 级比率修正；一步丢掉或复制整块 PCM 容易产生爆音。设备切换、休眠恢复和时间戳跳变时应重置积分状态，避免旧误差驱动新设备。

## 生命周期状态机

```text
Uninitialized -> Configured -> Priming -> Running
Running -> Reconfigure -> Priming
Running -> Bypassed / Muted
任意状态 -> Stopping -> Closed
```

`Priming` 用于积累噪声、AEC 或电平估计。采样率、声道、设备或路由变化应产生新代次；不能把旧设备的滤波器、延迟和增益状态直接继承。旁路时仍要维持媒体时间连续，不能因为不处理而丢掉块。

## 实时线程实现

- 回调中不做磁盘 I/O、网络请求、等待大锁或无界分配。
- 预分配工作缓冲；跨线程传递不可变音频块或明确所有权的池对象。
- 每个阶段有固定最坏处理时间，超时要记录并采用明确定义的旁路/降级策略。
- 配置变更通过版本化快照在块边界应用，避免处理半块时参数被另一线程修改。

## 可观测与故障注入

记录输入/输出能量、峰值、削波、噪声估计、VAD 概率、增益、AEC 延迟/收敛、处理耗时、队列深度、重采样比和缺块数。分别注入恒定噪声、脉冲噪声、双讲、播放参考丢失、设备切换、CPU 抢占和采样时钟偏差。

验收不能只听一段录音：要比较语音失真、残余回声、响度稳定、静音流量、端到端延迟和实时截止违约。

## 常见误区

- NS、AGC 开得越强越好：强处理通常以语音失真和泵动为代价。
- VAD=false 就代表没有人说话：分类存在误判，且它与业务静音是不同状态。
- AEC 只需要麦克风输入：没有时间对齐的播放参考无法建模回声路径。
- 缓冲能永久解决时钟漂移：固定频偏最终一定会填满或抽空缓冲。
