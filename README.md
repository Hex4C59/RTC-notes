# RTC 实时通信笔记

面向 RTC 开发学习、复习和工程查阅的 Obsidian 知识库，涵盖 WebRTC、音视频处理、媒体传输、网络质量、客户端、服务端及排障。

## 从哪里开始

1. 打开 [RTC 知识总览](00-知识地图/RTC%20知识总览.md)，按首页选择开始学习、继续上次或查概念。
2. 第一次阅读建议依次学习 [RTC](01-基础/RTC.md)、[实时媒体链路](01-基础/实时媒体链路.md)、[端到端延迟](01-基础/端到端延迟.md)。
3. 用 Obsidian 打开仓库文件夹，即可查看 Canvas 学习路线、专题知识树及双向链接。

## 阅读说明

- 笔记使用 Markdown 和 Obsidian 的 `[[双向链接]]`；GitHub 网页不完整支持这种链接和 `.canvas` 白板，推荐在 Obsidian 中阅读。
- P0、P1、P2 表示学习优先级；笔记状态表示内容完善程度，不代表学习者已掌握。
- 命令、API 和实现细节需对照实际使用的协议、库及平台版本。

## 公开范围

公开版本包含核心知识笔记、导航与模板。`90-参考资料` 中的整本书籍、论文全文、岗位调研和下载核验记录，以及 `.obsidian` 等本机配置保留在本地，不纳入公开版本。

部分笔记保留了指向本地参考区的链接或来源路径，克隆公开仓库后这些本地资料入口不可用；核心笔记与专题之间的链接仍可在 Obsidian 中使用。个人学习进度页提供空白记录模板，不表示任何人的实际学习成果。
