# 视频编码地图

## 关系速览

```mermaid
flowchart LR
    Camera["摄像头图像"] --> YUV["YCbCr 与色度抽样"]
    YUV --> Pred["帧内 / 帧间预测"]
    Pred --> Residual["残差变换、量化、熵编码"]
    Residual --> Codec["H.264 / HEVC 码流"]
    Codec --> GOP["GOP 与参考依赖"]
    GOP --> RTP["RTP 包化与网络传输"]
    Codec --> Layers["Simulcast 或 SVC 分层"]
```

## 数据表示与压缩工具

- [[YCbCr 与色度抽样]]：表示亮度、色度、位深和平面布局。
- [[视频编解码]]：理解质量、码率、延迟和错误扩散的共同问题。
- [[帧内与帧间预测]]：移除空间和时间相关性。
- [[变换量化与熵编码]]：压缩残差并生成可传输语法。
- [[GOP 与参考帧]]：组织随机访问、重排序和解码依赖。

## 编码标准与分层

- [[H264]]：RTC 中广泛使用的 AVC 码流与低延迟配置。
- [[H264 RTP 负载格式]]：把 NALU 通过单包、聚合和 FU-A 分片送入 RTP。
- [[视频 RTP 接收与组帧状态机]]：从 RTP 分片重建访问单元并检查参考依赖。
- [[HEVC]]：使用 CTU、更多预测和滤波工具提高压缩效率。
- [[Simulcast]]：发送多路独立编码供接收侧选择。
- [[SVC]]：在单一码流内组织可丢弃的空间、时间或质量层。

## 建议学习路径

先理解 YCbCr 和色度抽样，再沿预测、残差、变换量化、熵编码和参考结构学习通用压缩链。之后比较 H.264/HEVC 的码流与工程边界，最后研究 Simulcast/SVC 如何支持 SFU 按网络和布局选层。

## 掌握标准

- 能解释码率下降为何可能增加模糊、块效应和错误扩散。
- 能区分帧、切片、NAL 单元、RTP 包以及解码/显示顺序。
- 能说明关键帧、GOP、参考帧、Simulcast 和 SVC 对恢复与带宽的影响。
