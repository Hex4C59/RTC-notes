## 13.1 命令行观察与实验 · P0

### ffprobe 媒体检查

读取流、编码、采样率、像素格式、时间基、包和帧信息，验证自己的判断。

### ffmpeg 转换与生成

练习提取音频、转码、重采样、缩放和生成测试源，给 RTC 模块准备可控输入。

### ffplay 与裸数据播放

明确裸 PCM/YUV 缺少哪些格式信息；播放命令要与真实数据参数一致。

**本组练习：** 用 ffprobe 检查通话测试素材的编码、时间基和帧信息，生成可重复输入。

**掌握标准：** 完成上述练习，能说明输入输出、状态、时间或资源边界，并用抓包、日志、样本或可复现操作解释至少一个异常结果。

**配套详解：** [[码流与容器]]。

## 13.2 媒体对象与库职责 · P1

### AVFormatContext 与 AVStream

认识容器/输入输出上下文和流信息；不要把流对象当成网络连接。

### AVCodecContext、AVPacket、AVFrame

分别理解编解码状态、编码数据包和原始媒体帧；AVPacket 不是 RTP 包。

### 各库的分工

区分 libavformat、libavcodec、libavutil、libswresample、libswscale、libavfilter。

**本组练习：** 画出解复用、Packet、Codec、Frame 的所有权与数据流转关系。

**掌握标准：** 完成上述练习，能说明输入输出、状态、时间或资源边界，并用抓包、日志、样本或可复现操作解释至少一个异常结果。

**配套详解：** [[复用与解复用]] · [[AVPacket 与 AVFrame]]。

## 13.3 现代解码与编码流程 · P1

### 打开输入与取得参数

学习 avformat_open_input、查流、创建编解码上下文和参数复制。

### send/receive 状态机

使用 avcodec_send_packet/receive_frame 和 send_frame/receive_packet，处理 EAGAIN 与排空。

### 缓冲引用与资源释放

学习分配、引用、unref/free；跨线程传递时明确对象和底层数据的所有权。

**本组练习：** 使用一包多帧、EAGAIN 和输入结束场景检验 send/receive 与 drain。

**掌握标准：** 完成上述练习，能说明输入输出、状态、时间或资源边界，并用抓包、日志、样本或可复现操作解释至少一个异常结果。

**配套详解：** [[FFmpeg 解码状态机]]。

## 13.4 RTC 接入与版本意识 · P1

### 时间基转换与实时节奏

从文件读取不代表应尽快发完；按媒体时间调度，并保持 PTS/时钟单位一致。

### 重采样与像素变换

把解码输出适配到 Opus、视频编码器或播放设备所需格式。

### 旧 API 与新代码边界

旧书中的 av_register_all、avcodec_decode_video 等按历史接口理解；新工程依选定版本文档。

**本组练习：** 将测试素材按媒体时间送入 RTC，验证重采样、缩放和时间基换算。

**掌握标准：** 完成上述练习，能说明输入输出、状态、时间或资源边界，并用抓包、日志、样本或可复现操作解释至少一个异常结果。

**配套详解：** [[PTS DTS 与时间基]] · [[FilterGraph 重采样与缩放]]。

## 专题验收

写一个读取媒体文件并输出 PCM 或 YUV 的小程序；检查每次送入/取出的对象、时间戳和资源释放，再把输出接给 MiniRTC。

能画出“解封装 → 解码 → 原始帧 → 处理 → 编码 → 封装”的数据路径，并正确处理多次输出、EAGAIN 和结束排空。

记录：所用版本与设备、输入与参数、正常结果、异常结果、证据位置、尚未解决的问题。没有实验记录时，不把目录勾选当作掌握证据。
