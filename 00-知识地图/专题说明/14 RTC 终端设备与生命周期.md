## 14.1 设备接口与音频路由 · P1

### 平台采集与播放接口

选择一个平台深入：Android 的 AAudio/Oboe 与 Camera2、Apple 的 AVAudioSession/AVFoundation、Windows 的 WASAPI/Media Foundation、Linux 的 ALSA/PipeWire/V4L2。核对目标系统版本和权限，避免假设所有接口都提供相同格式与时序。

### 蓝牙、耳机与设备切换

路由切换可能改变采样率、声道、设备周期和实际延迟。需要先停止旧设备、协商新格式、重建必要的处理状态，并观察短暂欠载；蓝牙通话与媒体播放模式不能混用同一延迟假设。

### 权限、抢占与热插拔

把权限拒绝、设备移除、被其他应用占用视为显式状态。设备恢复后重新验证格式与路由，并使 UI 和实际采集状态一致，不能仅靠旧设备句柄继续收发。

**本组练习：** 在一个目标平台测试扬声器、耳机、蓝牙、拒绝权限和设备热插拔。

**掌握标准：** 完成上述练习，能说明输入输出、状态、时间或资源边界，并用抓包、日志、样本或可复现操作解释至少一个异常结果。

**配套详解：** [[采集与渲染]] · [[音频路由与设备热插拔]]。

## 14.2 硬件编解码与渲染 · P1

### 硬件能力与软件回退

查询 profile、level、分辨率、色深、并发实例和输入格式限制。回退时需要考虑时间戳连续性、关键帧和解码重配置，并记录是能力不支持还是运行中失败。

### GPU 表面与零拷贝

理解 CPU 内存、纹理、硬件 surface 和同步栅栏的所有权。零拷贝依赖采集、编解码和渲染之间可共享的格式与设备上下文，跨 GPU 或跨 API 转换仍可能产生拷贝。

### 渲染节奏与功耗

测量解码完成到真正呈现的等待，区分丢帧、显示刷新率与重复呈现。把热降频、后台策略和电池消耗纳入长时测试，避免只看短时间平均 FPS。

**本组练习：** 比较软硬编路径的格式、surface 寿命、首帧、P99 耗时及功耗。

**掌握标准：** 完成上述练习，能说明输入输出、状态、时间或资源边界，并用抓包、日志、样本或可复现操作解释至少一个异常结果。

**配套详解：** [[视频编解码]] · [[YCbCr 与色度抽样]]。

## 14.3 SDK 生命周期与接口 · P1

### 线程归属与跨语言绑定

标注 JNI、Objective-C、C 接口及业务回调的执行线程和对象寿命。跨语言传递 buffer 时写清借用或转移语义，不能在 native 对象释放后继续触发托管层回调。

### 前后台与中断恢复

应用切后台、锁屏、电话中断或系统挂起后，采集和网络能力取决于平台权限与策略。恢复时重新检查会话、设备及路径状态，区分重启设备、ICE restart 和重建会话。

### 版本兼容与发布接口

固定 WebRTC 提交、工具链、ABI 和接口契约；记录废弃参数与行为变化。升级应通过设备和互通矩阵验证，不能用能够编译代替运行兼容性。

**本组练习：** 重复执行通话、切后台、恢复、挂断，核对线程和跨语言回调的寿命。

**掌握标准：** 完成上述练习，能说明输入输出、状态、时间或资源边界，并用抓包、日志、样本或可复现操作解释至少一个异常结果。

**配套详解：** [[Native WebRTC 线程模型]] · [[WebRTC 会话生命周期]]。

## 14.4 平台验收与性能 · P1

### 设备与系统测试矩阵

按 OS、机型、音频路由、硬件编解码器和权限状态建立覆盖矩阵。优先覆盖实际发布平台，明确未测设备，避免从单机结果推断所有终端表现。

### 崩溃与资源诊断

使用符号化堆栈、native 内存工具、线程采样和平台日志定位泄漏、死锁与悬空引用。特别测试反复进退房、取消和析构期间的回调竞争。

### 实时线程预算

给采集、编码、网络和播放线程分别统计回调耗时、排队与 P95/P99。实时路径避免长锁、同步 IO 和无界分配；优化必须以目标设备测量为依据。

**本组练习：** 建立目标机型与系统矩阵，记录一次资源或调度异常的定位证据。

**掌握标准：** 完成上述练习，能说明输入输出、状态、时间或资源边界，并用抓包、日志、样本或可复现操作解释至少一个异常结果。

**配套详解：** [[Stats 指标与故障映射]] · [[采集与渲染]]。

## 专题验收

在一个实际目标平台完成采集预览、通话、切换设备、后台恢复和挂断；固定版本，保留延迟、欠载、资源占用及失败日志。

能解释每个设备对象和媒体缓冲的创建、使用和销毁线程；能复现并定位设备切换或后台恢复失败。

记录：所用版本与设备、输入与参数、正常结果、异常结果、证据位置、尚未解决的问题。没有实验记录时，不把目录勾选当作掌握证据。
