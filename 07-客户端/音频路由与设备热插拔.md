# 音频路由与设备热插拔

> [!tip] 阅读提示
> **前置：** [[采集与渲染]]、[[RTC 音频预处理状态机]]。
> **初读：** 读到「初读到此为止」就停。弄清：路由/热插拔会改采样率、延迟和回声路径；切换后 APM 往往要重建代次。
> **深入：** 平台差异与观测，真机联调时再读。

## 一句话说明

音频路由决定麦克风/扬声器（听筒、扬声器、耳机、蓝牙、USB）如何接到采集与播放图；热插拔与路由变更会改变采样率、延迟、回声路径和权限状态。它是客户端设备层问题，不是网络丢包，也不等于业务“切换摄像头”。

## 先记住这三句

1. 音频路由 = 麦/听筒/扬声器/耳机/蓝牙接到采集与播放图；热插拔会改格式、延迟和**回声路径**。
2. 蓝牙已连接 ≠ 音频已走蓝牙；路由切换通常**不需要** PeerConnection renegotiation。
3. 切换成功后 AEC/APM 要跟代次重置——只改 UI 选中项、图没重建，就会「看起来切了、实际还在旧麦」。

## 问题边界

- **上游：** OS 设备事件、通话模式（media/voice）、用户选择、蓝牙 HFP/A2DP 配置文件。
- **下游：** 采集/播放设备 ID、回调块长、AEC 参考路径、APM 代次、用户可听路由。
- **易混淆：**
  - 路由切换 ≠ PeerConnection renegotiation（通常不需要）。
  - 蓝牙已连接 ≠ 音频已走蓝牙（profile/通话模式不对会仍走听筒）。
  - 设备枚举列表变化 ≠ 图已重建成功。

## 核心机制

```text
设备到达/移除/默认设备变化
  -> 更新枚举与权限
  -> 选择新路由（策略：用户指定 > 通话场景默认 > OS 默认）
  -> 停旧回调 / 启新回调（或无缝切换）
  -> 通知 APM/AEC：新代次、清滤波器、重估延迟
  -> 保持 RTP 时间线连续（必要时插入静音/PLC）
```

### 路由状态（示意）

| 状态 | 含义 |
| --- | --- |
| Unbound | 未选设备 |
| Binding | 打开设备、协商格式 |
| Active | 回调运行 |
| Switching | 热切换中，可能双开或桥接 |
| Failed | 打开失败/被抢占 |
| Released | 释放 |

## 工作流程

1. 监听设备变更与路由意图（用户点蓝牙、插拔有线耳机）。
2. 选择目标输入/输出；处理权限拒绝与被其他 App 抢占。
3. 切换时尽量缩短无声窗口；播放侧避免爆音（淡出/淡入）。
4. 向 APM 发送路径变化：重置 AEC/AGC 状态，重新 delay estimate。
5. 更新统计：设备名、路由、切换耗时、欠载/溢出次数。

## 具体例子

通话中插入 Type-C 耳机。正确路径：输出切到有线耳机，输入可能仍用手机麦或头麦；APM generation+1，AEC 重新对齐。错误路径：输出切了但 AEC 参考仍取扬声器 tap，远端听到明显回声。

## 关键对象与数据

- deviceId、label、transport（内置/USB/BT）、方向（in/out）
- 采样率、声道、回调 buffer size、独占/共享模式
- 通话模式：ringtone / voice communication / media
- AEC 参考点：播放图 tap 位置是否仍正确
- 代次号：每次成功切换 +1，供 [[RTC 音频预处理状态机]] 使用

## 工程要点

- **AEC 必跟随路由：** 扬声器变蓝牙后旧回声路径无效，不重置会“回声回来”或近端被挖空。
- **采样率漂移：** 不同设备时钟不同，切换后重采样/漂移控制要重置积分。
- **移动端通话模式：** VoIP 模式才有完整 AEC/AGC 链路的平台很多；漏设会导致路由怪异。
- **不要在音频回调里做设备枚举或 UI。**
- 与视频设备热插拔分开处理：相机被抢占不应误停音频，除非产品要求。

## 常见误区与故障表现

- **只改 UI 选中项，不重建图：** 实际仍从旧 mic 采集。
- **切换后不重置 APM：** 回声或增益泵动。
- **把无声窗口当网络卡顿：** 先看本地 device switch 日志。
- **蓝牙弹窗时阻塞信令线程：** 导致 ICE/DTLS 连带超时。

## 观测与验证

- 日志：旧/新 deviceId、采样率、buffer、切换耗时、APM generation、AEC delay。
- 用例：听筒↔扬声器、插拔有线耳机、蓝牙连接/飞行模式、通话中来电抢占、App 后台恢复。
- 听感：切换爆音、回声、双侧音量跳变、首字吞音。
