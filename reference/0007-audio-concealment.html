PLC：生成替代音频

PLC（Packet Loss Concealment，丢包隐藏）在缺少可用音频数据时，根据已有信号生成替代输出，尽量减轻缺包造成的听感影响。Opus 标准把它描述为解码侧功能，允许不同实现。

需要区分含义
正常解码利用及时可用的编码数据，解码出对应音频。
PLC 输出缺少对应数据时生成替代音频，不保证与正常解码结果一致。
网络收包PLC 本身没有接收或重传原包，不能据此认定原包按时到达。

一个固定时序例子

某包对应的声音计划在 50–70 ms 播放，包到 90 ms 才到。若没有及时可用的恢复数据，可用 PLC 为 50–70 ms 提供替代音频；后续正常包按既定安排处理。忽略处理耗时，仅用于理解机制。

声音持续输出 ≠ 原包已经收到 ≠ 缺失内容被准确还原。

已经播放的声音不能由迟到包改写。PLC 的效果取决于已有信号、缺失持续时间与实现；不保证完全听不出问题。

来源：RFC 6716 §4.4。本卡讨论基本机制，不把标准中的参考算法当作所有当前实现。
